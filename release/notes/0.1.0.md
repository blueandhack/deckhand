**First alpha of Deckhand.app** — the Mac side of [Deckhand](https://github.com/blueandhack/deckhand), the desk display for Claude Code, packaged as one notarized app. It is an alpha: it has been tested end to end on one Mac, and the list of what has *not* been verified is below.

**Requires:** Apple Silicon, macOS 14 or later, and a Deckhand display (firmware is flashed from the repo with `./flash.sh`). No Node, Homebrew or clone of the repo is needed for the app itself.

### Install

1. Download `Deckhand-0.1.0.dmg` below, open it, and drag **Deckhand** to **Applications**.
2. Open it from Applications. The setup window:
   - offers to stop a Deckhand already running from the repo (its launch agent is moved to `~/Deckhand-backups`, not deleted);
   - lists every change it will make to Claude Code's settings and asks first, backing up before it writes;
   - asks macOS for Bluetooth once (refuse it and USB still works), then runs the host in the background, starting at login.
3. Restart Claude Code so it picks up the hooks.

### What's in it

- **Menu bar:** Claude, Codex and Gemini usage as two-row columns (5-hour over weekly), session counts and a needs-input badge, in four sizes plus *Automatic*, which shrinks the item when the menu bar runs out of room (MacBook notch).
- **Dropdown:** connection, usage per service with reset times, and every session with its state.
- **Settings window:** General, Menu Bar, Devices (pairing, which display Bluetooth follows, this Mac's name and icon), Claude Code (hooks, Codex hooks switch), About (updates, host log, setup, uninstall).
- **Its own Node and host**, run by launchd and restarted if it crashes or hangs.
- **Updates itself** with Sparkle.

### Not verified yet

- A Mac with no Node or Homebrew installed (the build checks that nothing links outside the app, which stands in for it).
- A notched MacBook screen's menu bar (the shrink-to-fit logic was tested by forcing an overflow on an external display).
- A first-time Bluetooth prompt raised from a fresh macOS permission state.
- **Uninstall** (Settings › About).
- **Gemini usage** reads an undocumented local interface of the Gemini app; a Gemini update may make it disappear (nothing breaks).
