**Tenth alpha of Deckhand.app.** Installed 0.1.x copies update to this automatically (Sparkle); new installs download the DMG below.

**Requires:** Apple Silicon, macOS 14 or later, and a Deckhand display (firmware is flashed from the repo with `./flash.sh`). No new firmware is needed for this release.

### What's new

- **Codex in auto mode no longer shows "needs input".** In auto mode, Codex's own reviewer approves commands, but Codex still told Deckhand about each approval as if it were a question for you. So the session showed "needs input" the whole time, and each approval waited 15 seconds for a tap on the display before Codex carried on. Deckhand now checks the session's approval setting: approvals Codex handles itself keep the session "working" and run without the wait. When Codex really is asking you, it shows on the display as before.

Nothing else changes from 0.1.8.

### Install (new users)

1. Download `Deckhand-0.1.9.dmg`, open it, and drag **Deckhand** onto **Applications**.
2. Open it from Applications and follow the setup window (it asks before touching Claude Code's settings and backs up first).
3. Restart Claude Code so it picks up the hooks.

### Known limits

With Claude Code switched off on the Agents pane, the display's usage cards show dashes rather than disappearing; the firmware is unchanged.

### Still not verified

Whether Codex's auto-reviewer can ever hand a request back to you; the USAGE tab with Codex **and** Antigravity both reporting, on the display itself; anything new on the smaller (2.8") display; a Mac with no Node or Homebrew installed; a notched MacBook screen's menu bar; a first-time Bluetooth prompt from a fresh permission state; and **Uninstall**.
