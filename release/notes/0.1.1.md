**Second alpha of Deckhand.app.** Installed 0.1.0 copies update to this automatically (Sparkle); new installs download the DMG below.

**Requires:** Apple Silicon, macOS 14 or later, and a Deckhand display (firmware is flashed from the repo with `./flash.sh`).

### What's new

- **A proper install window.** Opening the DMG now shows Deckhand and the Applications folder with an arrow between them, a picture of the menu bar Deckhand will live in, and the version — instead of a bare folder. The mounted disk carries Deckhand's icon.
- **Hangs explain themselves.** If the background host's work loop ever stalls, its log now names the exact step it is stuck in and for how long, so a rare hang seen on the development Mac can be tracked down the next time it happens. No change in behaviour otherwise.

### Install (new users)

1. Download `Deckhand-0.1.1.dmg`, open it, and drag **Deckhand** onto **Applications**.
2. Open it from Applications and follow the setup window (it asks before touching Claude Code's settings and backs up first).
3. Restart Claude Code so it picks up the hooks.

### Still not verified

A Mac with no Node or Homebrew installed; a notched MacBook screen's menu bar; a first-time Bluetooth prompt from a fresh permission state; **Uninstall**; and Gemini usage, which reads an undocumented local interface of the Gemini app.
