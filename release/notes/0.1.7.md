**Eighth alpha of Deckhand.app.** Installed 0.1.x copies update to this automatically (Sparkle); new installs download the DMG below.

**Requires:** Apple Silicon, macOS 14 or later, and a Deckhand display (firmware is flashed from the repo with `./flash.sh`). No new firmware is needed for this release.

### What's new

- **Sessions no longer disappear while a long task runs.** A Claude Code session that went 20 minutes without activity, for example while waiting on a long background task, was dropped from the session counts and the display. Deckhand now checks whether the session's Claude process is still running: an open session stays however quiet it is, and one whose process has exited shows as ended straight away instead of lingering for 20 minutes. Codex and Antigravity sessions keep the old 20-minute rule. A session already dropped by an earlier version comes back the next time it does anything.
- **Settings > Agents: switch Claude Code, Codex or Antigravity off completely.** Each agent has three switches:
  - **On.** When it is off, Deckhand stops reading that agent's usage (no more background `agy` or Codex refresh runs). Its sessions are left out of the menu bar, the menu and the display, and its hooks never wait on the display.
  - **Usage beside the icon.** This moved here from the Menu Bar pane.
  - **Usage in the menu.** This one is new.
  
  With both display switches off, the agent is still tracked and still shown on the display, but not on the Mac.

### Install (new users)

1. Download `Deckhand-0.1.7.dmg`, open it, and drag **Deckhand** onto **Applications**.
2. Open it from Applications and follow the setup window (it asks before touching Claude Code's settings and backs up first).
3. Restart Claude Code so it picks up the hooks.

### Known limits

With Claude Code off, the display's usage cards show dashes rather than disappearing; the firmware is unchanged in this release.

### Still not verified

The USAGE tab with Codex **and** Antigravity both reporting, on the display itself; anything new on the smaller (2.8") display; a Mac with no Node or Homebrew installed; a notched MacBook screen's menu bar; a first-time Bluetooth prompt from a fresh permission state; and **Uninstall**.
