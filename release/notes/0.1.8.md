**Ninth alpha of Deckhand.app.** Installed 0.1.x copies update to this automatically (Sparkle); new installs download the DMG below.

**Requires:** Apple Silicon, macOS 14 or later, and a Deckhand display (firmware is flashed from the repo with `./flash.sh`). No new firmware is needed for this release.

### What's new

- **Every session in the menu shows which agent it belongs to.** Each row now starts with `CC`, `CODEX` or `AGY`, in a column of its own so the project names line up. Before, only Codex and Antigravity sessions were labelled, faintly and after the project name, while Claude Code sessions had no label. The display already labels every session, and is unchanged.

Nothing else changes from 0.1.7, including the Agents switches and the fix that keeps long-running sessions listed.

### Install (new users)

1. Download `Deckhand-0.1.8.dmg`, open it, and drag **Deckhand** onto **Applications**.
2. Open it from Applications and follow the setup window (it asks before touching Claude Code's settings and backs up first).
3. Restart Claude Code so it picks up the hooks.

### Known limits

With Claude Code switched off on the Agents pane, the display's usage cards show dashes rather than disappearing; the firmware is unchanged.

### Still not verified

The USAGE tab with Codex **and** Antigravity both reporting, on the display itself; anything new on the smaller (2.8") display; a Mac with no Node or Homebrew installed; a notched MacBook screen's menu bar; a first-time Bluetooth prompt from a fresh permission state; and **Uninstall**.
