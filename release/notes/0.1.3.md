**Fourth alpha of Deckhand.app.** Installed 0.1.x copies update to this automatically (Sparkle); new installs download the DMG below.

**Requires:** Apple Silicon, macOS 14 or later, and a Deckhand display (firmware is flashed from the repo with `./flash.sh`). **The display needs new firmware** to show Antigravity sessions and usage; an older display keeps working and simply does not show them.

### What's new

- **Antigravity, everywhere.** Google has retired Gemini CLI in favour of Antigravity CLI (`agy`), and Deckhand now calls it Antigravity throughout: the menu bar's **AG** column (it was GM) and its Antigravity section.
- **Antigravity sessions on the display.** They appear beside Claude Code and Codex, tagged **AGY** with their own animated mark, showing working or ready, the model and your latest prompt.
- **An Antigravity hook.** Settings › Hooks › *Antigravity hook* (on by default when Antigravity is installed). It adds the model and the latest prompt to Antigravity sessions. It never answers or holds up a tool call: Antigravity has no hook that runs while its approval prompt is on screen, so those prompts are still answered in Antigravity.
- **Antigravity usage without the app.** With only `agy` in a terminal, Deckhand now reads usage from the CLI itself (no model turn, so it costs no quota). The figure shown is your most-used Gemini limit, so if you mostly use Argon, you see Argon's.
- **Antigravity usage on the display.** A new **AGY** strip on the USAGE tab. When Codex is reporting too, the tab makes room for both strips.
- **A smaller download.** About 35 MB instead of 52 MB, and about 119 MB installed instead of 155 MB.

### Install (new users)

1. Download `Deckhand-0.1.3.dmg`, open it, and drag **Deckhand** onto **Applications**.
2. Open it from Applications and follow the setup window (it asks before touching Claude Code's settings and backs up first).
3. Restart Claude Code so it picks up the hooks.

### Still not verified

The USAGE tab with Codex **and** Antigravity both reporting, on the display itself (it is checked offline only); anything new on the smaller (2.8") display; a Mac with no Node or Homebrew installed; a notched MacBook screen's menu bar; a first-time Bluetooth prompt from a fresh permission state; and **Uninstall**. Antigravity's usage and session data come from interfaces Google does not document and can change in an update.
