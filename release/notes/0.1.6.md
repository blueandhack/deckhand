**Seventh alpha of Deckhand.app.** Installed 0.1.x copies update to this automatically (Sparkle); new installs download the DMG below.

**Requires:** Apple Silicon, macOS 14 or later, and a Deckhand display (firmware is flashed from the repo with `./flash.sh`). No new firmware is needed for this release.

### What's new

- **The restart log tells the truth again.** Since 0.1.5, the background host clears its status file when it stops cleanly, so the menu bar shows "Stopped" at once. That also left the restart history (`deckhand-service.sh status`) saying every clean restart had "last tick unknown (... /tmp cleared?)". The host now records its last tick before it exits, so a clean restart reads as one, and a host that had stalled before it was stopped is still reported as stalled.

Nothing else changes from 0.1.5, including its much lower memory use.

### Install (new users)

1. Download `Deckhand-0.1.6.dmg`, open it, and drag **Deckhand** onto **Applications**.
2. Open it from Applications and follow the setup window (it asks before touching Claude Code's settings and backs up first).
3. Restart Claude Code so it picks up the hooks.

### Still not verified

Memory use over a full day on 0.1.5 and later (measured at 13 minutes so far); the USAGE tab with Codex **and** Antigravity both reporting, on the display itself; anything new on the smaller (2.8") display; a Mac with no Node or Homebrew installed; a notched MacBook screen's menu bar; a first-time Bluetooth prompt from a fresh permission state; and **Uninstall**.
