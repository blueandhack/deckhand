**Sixth alpha of Deckhand.app.** Installed 0.1.x copies update to this automatically (Sparkle); new installs download the DMG below.

**Requires:** Apple Silicon, macOS 14 or later, and a Deckhand display (firmware is flashed from the repo with `./flash.sh`). No new firmware is needed for this release.

### What's new

- **Gigabytes less memory.** Deckhand used to run a usage tool (ccusage) that re-read every Claude Code transcript you have on every update, about 1.25 GB each time, two at once, almost continuously. Deckhand now counts tokens itself, reading each transcript once and then only what is added: a few MB instead of about 2.5 GB.
- **A leaner background host.** It now runs with memory settings tuned for a process that mostly waits, and Settings gives memory back when you close it.
- **Start, Stop and Restart answer you.** Clicking one shows what it is doing ("Stopping Deckhand…"), then what happened ("Restarted."), or says so if nothing changed within 20 seconds. Before, nothing on screen moved.
- **The USAGE tab's token counts are Claude's own.** The 5-hour and 7-day cards are Claude's quota, so their token counts no longer include Codex. The FABLE line counts Claude Fable models only (a local model with "Fable" in its name was being counted), and the weekly count is always the current week.

### Install (new users)

1. Download `Deckhand-0.1.5.dmg`, open it, and drag **Deckhand** onto **Applications**.
2. Open it from Applications and follow the setup window (it asks before touching Claude Code's settings and backs up first).
3. Restart Claude Code so it picks up the hooks.

### Still not verified

The new memory figures on a long-running copy of this release (they were measured on the code, not yet on the installed app); the USAGE tab with Codex **and** Antigravity both reporting, on the display itself; anything new on the smaller (2.8") display; a Mac with no Node or Homebrew installed; a notched MacBook screen's menu bar; a first-time Bluetooth prompt from a fresh permission state; and **Uninstall**.
