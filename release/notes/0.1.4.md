**Fifth alpha of Deckhand.app.** Installed 0.1.x copies update to this automatically (Sparkle); new installs download the DMG below.

**Requires:** Apple Silicon, macOS 14 or later, and a Deckhand display (firmware is flashed from the repo with `./flash.sh`). No new firmware is needed for this release.

### What's new

- **Far less memory.** The background host (*Deckhand Host* in Activity Monitor) measured 327 MB after a day of running. Most of that was one cache: opening the PROJECTS tab kept a copy of the first prompt of every project you have ever used, about 100 MB on a Mac with 800 projects, until the host restarted. It now keeps only what it needs (measured: 108 MB down to 0.2 MB).
- **Steadier over long runs.** Bluetooth devices nearby (phones change their address every few minutes) were remembered forever; the host now forgets the ones it could never connect to. It also stops re-reading Codex logs and session transcripts every five seconds when they have not changed.
- **Release notes in the update window.** Sparkle's update window now shows what changed, starting with this update. Before, it was empty and the notes were only on the GitHub page.

### Install (new users)

1. Download `Deckhand-0.1.4.dmg`, open it, and drag **Deckhand** onto **Applications**.
2. Open it from Applications and follow the setup window (it asks before touching Claude Code's settings and backs up first).
3. Restart Claude Code so it picks up the hooks.

### Still not verified

The host's memory over a full day on this release (the fix was measured on the code path that caused it, not yet on a long-running host); the USAGE tab with Codex **and** Antigravity both reporting, on the display itself; anything new on the smaller (2.8") display; a Mac with no Node or Homebrew installed; a notched MacBook screen's menu bar; a first-time Bluetooth prompt from a fresh permission state; and **Uninstall**.
