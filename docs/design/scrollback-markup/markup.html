What is on the glass

  1. Heading rule. One COLOR_LABEL pixel under the last row of a heading only - a rule between a wrapped heading's two rows would read as two headings.
  2. Hanging bullets. A wrapped list item's continuation starts at its own text column, not back at the marker.
  3. The block's edge. A 2px COLOR_LABEL bar at the block's own x, every row of it, breaking on its own between blocks - no top/bottom flag exists.
  4. The language row. Dim, on the card ground, costing one row - only when the fence named a language.
  5. Wrapped code keeps its shape. A continuation hangs to the source line's own indent and carries + in the gutter, capped at SCROLL_HANG_MAX.
  6. Collapsed links keep the fact they existed. text~ for markdown, a shortened host/.../tail~ for a bare URL.
  7. A tool row beside a code block carries no edge bar. The pre-existing flag-inheritance defect this branch closed in passing (Task 7).
