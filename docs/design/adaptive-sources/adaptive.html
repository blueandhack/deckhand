The sparkline is the only element with an open question against it

The redesign shipped with “the sparkline has never been read by a human at 320×480 — whether 31 caps in a 260×32 box read as a trend or as texture” recorded as unverified. drawUsageSpark scales with its height (cy = y + h - 3 - ((h-5)·v)/100), so the fixed 0–100 scale gains real vertical resolution as the band grows. At 96px it is roughly one pixel per percentage point.

Why WEEK cannot simply be given air

rhythm() asserts every band gap equals the first, exempting only the pin bar, and its extra gaps are added to that check rather than excused from it. So 32 rows at one boundary fails it. WEEK has no band that should grow either — a WEEK sparkline would be a flat line pretending to be a trend, the ring moving 1.49 points across a 7-day window. That leaves re-pitching the uniform gap, which moves all six offsets.

The threshold

One full window of silence — derived, not chosen

A reading is dead once a whole window has passed with no refresh. Codex’s window already crosses the wire as cxWin and is stored as usage.cxWindowMin, so the threshold is data-driven: a plan with a different window moves it.

  • Below one window the number is merely stale, and that state already exists — QUOTA_STALE_SEC dims at 900s. Hiding is the stronger claim that nobody is running the tool: the host polled ~120,000 times and learned nothing.
  • It cannot flap. Age grows monotonically until a refresh arrives, so the edge fires once and a refresh brings the row straight back.

Claude never hides — the asymmetry is the design

Claude’s quota is account-level: the host polls OAuth whether or not you use Claude Code, so a reading arrives even at 0%. For it to reach days, the refresh token must have expired and the statusLine cache gone cold — that is broken auth, with a fix. A tidy Codex-only tab would conceal the only evidence of it.

What this page is, and is not

Every glyph is the real Spleen bitmap read out of the headers the firmware links, and every shared constant is the value parsed from board_es3c35p.h. It vouches for geometry. It cannot vouch for colour on the panel — that needs COLORTEST and a person.
